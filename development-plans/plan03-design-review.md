# Plan 03 interaction and design-tool review

Reviewed 2026-10-17. The calm editorial design, local fonts and existing Tailwind tokens remain the product direction. No new animation dependency, hosted runtime service, account, paid asset or card authorization was introduced.

## Section 01 - Feedback and motion

Property and image saves expose busy states, success messages and recoverable errors. Conflicting versions preserve writing; destructive/reload actions require focused confirmation dialogs. Gallery reordering and focal controls update previews directly. Saved-home changes provide concise live-region feedback. The saved heart has a restrained 150 ms scale transition; spinners and that transition use Tailwind `motion-safe:` variants. The hero keeps its reduced-motion/data-saver poster behavior. Keyboard focus, dialog Escape/cancel and returning focus to the trigger are covered by browser checks.

Avoid animated text in live-region notices, automatic scroll effects, continuous decorative movement or per-letter animation in form errors. Immediate readable feedback is more useful in an editorial workflow.

## Section 02 - Tools evaluated

| Tool                                                              | Review and decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ----------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Motion Primitives](https://github.com/ibelick/motion-primitives) | The official repository provides React motion components under [MIT](https://github.com/ibelick/motion-primitives/blob/main/LICENCE.md). Its [Text Morph source](https://github.com/ibelick/motion-primitives/blob/main/components/core/text-morph.tsx) uses `motion/react`, per-character spans and spring layout transitions. That pattern adds a dependency and motion behavior for notices that should remain immediately readable. Keep our existing native live regions and small Tailwind state transitions; no component code copied. |
| [Haikei](https://haikei.app/)                                     | Its official site offers configurable SVG/PNG generators without signup or a card. Exported vectors could suit a future one-off editorial illustration. The current original mark and material vignette already cover sparse legal/login/error pages, while the 28 photographs provide visual depth. No extra decorative export was needed or imported.                                                                                                                                                                                       |
| [Realtime Colors](https://www.realtimecolors.com/)                | Its official site visualizes color/font roles and describes contrast checking and exports. It is useful for comparing future palettes. Preserve the current measured palette and self-hosted fonts; evaluate contrast locally as well as in populated-browser axe/Lighthouse checks. No website source or licensed template copied, and no runtime integration.                                                                                                                                                                               |

These are evaluated production aids, not required installations. The public brand remains original and there is no claim that a third-party generator produced existing project SVGs.

## Section 03 - Token contrast

The closure evidence records locally calculated WCAG relative-luminance contrast for ink, muted and brand text against paper/white. These measurements support the existing text colors; browser checks cover actual rendered combinations. Borders and decorative muted details are not automatically certified as text. Human screen-reader and native zoom review remains the owner's optional review recorded under Plan 02.
